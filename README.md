## Main Idea
- Project Name: (Community Appointment)
- Feature:

Admin -- 

    - Admin User dapat membuat dashboard/realm/community baru (create community)
    
    - Admin User dapat menamakan dashboard, description, tema, goals, atau yang lainnya.
    
    - Kalau dashboard sudah dibuat, admin dapat menyalin url/link/token/qr-code dan dibagikan ke teman-teman; atau
    
    - Admin dapat meginvite teman-teman untuk masuk ke community tersebut.

Member --

    - Untuk member user dari community tersebut, member bisa masuk dari link yang dibagikan atau dengan memasukkan token cocok.
    
Dashboard mechanism --
    
    - Dalam dashboard tersedia calendar. Semua user dapat memilih tanggal di pada suatu tanggal di calendar tersebut.

    - Ada counter pada cell tanggal tersebut yang menghitung berapa banyak orang yang memilih tanggal tersebut.
    
    - Apabila pada tanggal tersebut sudah lebih dari atau sama dengan 50% dari banyaknya member, maka kegiatan dapat dilakukan yang diindikasikan dengan warna (misal=kuning)
    
    - Admin dapat meng-proceed tanggal tersebut untuk diadakan kegiatan dengan memilih button "adakan kegiatan"
    
    - Tanggal tersebut akan berubah warna menjadi hijau yang artinya "kegiatan siap diadakan"
    
    - Notifikasi akan muncul melalui email masing-masing pengguna
